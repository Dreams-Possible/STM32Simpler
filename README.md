> 
> 本项目最初设计用于裸机开发，现已不再维护。作者正在开发基于CMSIS-V2（FreeRTOS多线程）的新版本库，建议用户关注新项目。

## 📋 项目概述

STM32Simpler是一个基于STM32 HAL库和STM32CubeIDE的底层驱动库，旨在为STM32初学者提供一个易于上手、易于移植的完善驱动解决方案。

## 🚀 快速开始

### 环境要求
- **IDE**: STM32CubeIDE（推荐）或 Keil MDK
- **库**: STM32 HAL库
- **硬件**: STM32系列开发板（F103C8T6已验证）

### 基本使用步骤

1. **创建项目**: 使用STM32CubeMX生成基础工程
2. **导入驱动**: 将`New/Main/`目录下的文件复制到项目`Src/`和`Inc/`目录
3. **配置入口**: 在`main.c`中包含`SimpleMain.h`并调用初始化函数
4. **使用驱动**: 调用相应模块的函数实现功能

### 示例代码

```c
#include "SimpleMain.h"

int main(void) {
    // HAL初始化（由CubeMX生成）
    HAL_Init();
    SystemClock_Config();
    
    // STM32Simpler初始化
    Main_Initization();
    
    while (1) {
        // 主循环逻辑
        Main_While();
        HAL_Delay(10);
    }
}
```

## 📚 驱动模块说明

### 核心模块
- **SimpleMain**: 统一配置入口，简化初始化流程
- **LEDs**: LED灯控制，支持多种闪烁模式
- **Keys**: 按键检测，支持单击、长按、连击
- **UARTs**: 串口通信，支持DMA和中断模式

### 通信接口
- **IICs**: I2C总线驱动，支持多设备管理
- **SPIs**: SPI总线驱动，支持全双工通信
- **OLED096s**: OLED显示屏驱动，支持I2C/SPI接口

### 外设驱动
- **Timers**: 定时器配置，支持PWM输出
- **Encoders**: 编码器读取，支持正交编码
- **Motors**: 电机控制，支持PWM调速
- **MPU6050**: 六轴传感器，支持DMP姿态解算
- **W25Qx**: SPI Flash存储，支持读写擦除

## 🔧 开发理念

### 设计原则
1. **易用性**: 简化配置流程，降低入门门槛
2. **可读性**: 使用描述性命名，避免过度缩写
3. **模块化**: 功能独立，便于移植和复用
4. **兼容性**: 基于官方HAL库，确保长期支持

### 技术选型
- **HAL库**: ST官方主推，未来发展趋势
- **CubeIDE**: 免费，配置简单
- **C语言**: 嵌入式开发标准语言
